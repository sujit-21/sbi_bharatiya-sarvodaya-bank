4. SYSTEM RUN COMMANDS & APPLICATION STARTUP GUIDE (FRONTEND & BACKEND)

--------------------------------------------------------------------------------
1. CORE MAIN BACKEND API SERVER
--------------------------------------------------------------------------------
Backend Run Command:   npm run dev
Alternative Command:   node backend/server.js
Working Directory:     c:\my_project\ag10_banking
API Server Endpoint:   http://localhost:5000

--------------------------------------------------------------------------------
2. GLOBAL HEADQUARTERS PORTAL (HQ CONSOLE)
--------------------------------------------------------------------------------
Frontend Run Command:  npm run hq:frontend
Direct Directory:      cd headquarter/frontend && npm run dev (or npx vite)
Backend Run Command:   npm run hq:backend
Direct Directory:      node headquarter/backend/server.js
Target Users:          Super Admin (Rajesh Sharma), HQ Compliance Officers, Auditors

--------------------------------------------------------------------------------
3. BRANCHES AND EMPLOYEES PORTAL (BRANCH & STAFF CONSOLE)
--------------------------------------------------------------------------------
Frontend Run Command:  npm run branch:frontend
Direct Directory:      cd branches_and_employees/frontend && npm run dev (or npx vite)
Backend Run Command:   npm run branch:backend
Direct Directory:      node branches_and_employees/backend/server.js
Target Users:          Branch Managers (Priya Patel), Employees (Tellers, Loan Officers)

--------------------------------------------------------------------------------
4. CUSTOMERS PORTAL (RETAIL INTERNET BANKING)
--------------------------------------------------------------------------------
Frontend Run Command:  npm run customer:frontend
Direct Directory:      cd customers/frontend && npm run dev (or npx vite)
Backend Run Command:   npm run customer:backend
Direct Directory:      node customers/backend/server.js
Target Users:          Retail Bank Customers (Aarav Mehta, Diya Banerjee, etc.)
